# Single-Cell-Transcriptomic-Profiling-and-Systems-Biology-of-Glioblastoma
Modular, end-to-end scRNA-seq bioinformatics pipeline for Glioblastoma. Built in R (Seurat v5), it processes raw data through advanced systems biology to dissect tumor heterogeneity, map the microenvironment interactome, infer cellular trajectories, and identify master regulatory transcription factors.
